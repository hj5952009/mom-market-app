# 엄마의 시장 나침반 v2 (홈 화면 이름: 시장 나침반)

가족 한 분(어머님)을 위한 안드로이드 앱입니다. **코스피가 다음 거래일에 어디쯤에서 끝날지**를 범위와 오를 확률로,
문장 대신 숫자와 그래프로 보여 줍니다. **투자 권유가 아닌 통계 참고용**입니다.

2.1.0: Yahoo가 끝난 날 종가를 빈칸(null)으로 줄 때 같은 Yahoo의 공식 값(전일 종가·마지막 장 가격)으로 채워, 예측 날짜가 하루 밀리던 문제를 고침. 큰 숫자는 앱에 넣은 굵은 세리프(Noto Serif Bold, OFL)로 표시.

2.6.0(베타): 이주완 탭에 '사이클' 화면 추가 — D램·낸드 수출가격(한국은행 ECOS 수출물가지수, 계약통화 기준)으로 본 가격 사이클: 지금 국면, 오르는 속도(3개월 변화율), 20년 흐름과 하락기, 지난 상승기 비교, '상승률 반토막' 신호 뒤 6개월 결과. 계산은 `tools/memory/`(memcalc.js·build-memory.js, 단위 테스트로 노트북 분석과 같은 결과 확인)이고, `semi-data.yml`이 매일 같은 ECOS 표로 `memory.json`을 만들어 `semi-data` 가지에 `semi.json`과 함께 올린다(이 단계가 실패해도 semi.json은 그대로 올라감). 앱은 6시간마다 받아 쓰고, 못 받으면 묶어 둔 `www/data/memory.json`을 쓴다. DRAMeXchange 등 재배포가 제한된 가격 자료는 넣지 않는다.

2.5.0: 이주완 탭에 '모델'·'공급' 화면 추가 — 박사의 "메모리 가격은 공급(감산·가동률)이 정한다"는 주장으로 만든 D램 가격 모델. 모델: 국면, 하락 신호 8개(자동 4·수동 4), 가격 시나리오(A 박사 기본·B 감산 해제·C TrendForce·D 공급 모델). 공급: 생산능력·가동률, 가격 효과를 뺀 수출 물량, 환율, 모델 성적·사이클 길이. 자료는 `.github/workflows/semi-data.yml`이 매일 07:10(KST) 한국은행 ECOS에서 새로 받아 `tools/semi/` 모델로 다시 계산하고, 바뀌었으면 `semi-data` 가지의 `semi.json`에 올립니다. 앱은 그 파일을 받아 쓰고(6시간마다, '새 자료 확인' 버튼), 못 받으면 앱에 묶어 둔 `www/data/semi.json`을 씁니다. 손으로 고치는 자료(자동으로 못 받는 신호 `tools/semi/data/signals_static.json`, TrendForce 전망·고정거래가 CSV)는 고쳐서 main에 올리면 자료 작업만 다시 돌고 APK는 새로 만들지 않습니다. ECOS 인증키를 저장소 Secrets에 `ECOS_API_KEY`로 넣으면 더 빨리 받습니다(없으면 공개 sample 키). 저장소를 비공개로 바꾸면 앱이 semi.json을 받지 못하니, 그때는 자료 가지를 공개 저장소로 옮겨야 합니다.

2.4.1: 이주완 탭에 '회사 공시로 다시 확인했어요' 카드 추가 — 삼성 메모리 생산량(사업보고서, 1Gb 환산), SK하이닉스·삼성·마이크론 재고, 설비투자(DART·SEC). 요약의 '이번 급등' 판정을 주장 점검과 같게(절반만 맞음) 맞춤.

2.4.0: '이주완' 탭 추가 — 이주완 박사(반도체 애널리스트)의 메모리 반도체 주장 13개를 한국은행 통계·회사 실적으로 점검한 결과(요약·주장 점검·예측 기록), D램 가격 vs 생산·수출 물량 차트. 자료는 www/data/jw.json(검증 코드는 회준님 PC의 YouTubeArchive/people/이주완/model/verify).

2.3.0: '성상현' 탭 추가 — 블로그 '매크로 비욘드' 글 1,094개를 앱이 요약·정리(요약·관점 모델·주제·글·원칙), 관점 지수를 모델에 더한 검증(의미 있는 개선 없음 → 기본 예측은 그대로). 자료 만드는 방법은 tools/sung/.

2.2.2: 새 버전 확인을 다시 이 저장소 Releases로 되돌림(저장소는 공개 유지). 2.2.1은 쓰지 마세요.

2.2.0: 지표 11개의 '자료 상태' 점검(각 시장 시각·휴장일 기준으로 마지막 장까지 들어왔는지)을 예측·정보 탭에 표시하고, 늦거나 못 받은 지표가 있으면 10분 뒤 다시 받음.
매일 자료 점검: `.github/workflows/data-health.yml`이 평일 07:20·16:30(KST)에 앱과 같은 코드로 Yahoo 자료를 받아 점검(`tools/health-check.js`), 문제가 계속되면 실패로 표시되어 GitHub가 메일로 알림.

v2(2.0.0)는 v1을 전면 재작성했습니다. 내 종목·용어 사전·상식 카드·간밤 문장·3장 온보딩·오류 보내기 등은 모두 뺐고,
예측 모델(`www/js/model.js`, 한 글자도 바꾸지 않음)과 시세 받기·저장·이어 붙이기만 그대로 씁니다.

- **예측** 탭: 핵심 숫자(중심값·오를 확률·95% 범위), 최근 30거래일 + 예측 부채꼴(50/80/95%), 확률 분포 곡선,
  오를 확률 막대(40~60% 구간 표시), 50/80/90/95% 범위 사다리, 그리고 미국 장 전이면 SOX 결과별 시나리오,
  미국 장 뒤면 간밤 해외 지표 변화 막대.
- **기록** 탭: 적중률 4개, 예측 범위(80/95%) 띠와 실제 종가(1개월/3개월/전체), 목표 대비 실제 비율, 확신 정도별 방향 적중률,
  60일 롤링 95% 적중률, 최근 20거래일 결과 점.
- **달력** 탭(2.1.0): 거래일마다 그 전날 계산한 예측(중심값·80/95% 범위·오를 확률)과 실제 종가·장중 저가~고가를 나란히,
  칸 색으로 80%/95% 범위 적중, ○/×로 방향 일치. 이 달·전체·달별 적중률과 방향 일치율.
- **정보** 탭: 모델 설명(11개 지표), 안내, 평일 아침 알림 켜기·시간, 글씨 크기(1.0/1.15/1.3), 새 버전 확인, 버전, 데이터 출처.
- 차트는 라이브러리 없이 SVG로 직접 그립니다(`www/js/charts.js`). 모든 차트는 누르면 툴팁, 다크 모드는 시스템 설정을 따릅니다.
- 분포 곡선은 모델이 낸 분위수(2.5~97.5%)로 앱에서 만듭니다(`Compute.densityFromQuantiles`, 설명은 소스 주석).
- 예측: 폰이 Yahoo Finance 일봉(처음 10년치, 그다음 1달치만 받아 이어 붙임)을 받아 `model.js`로 계산합니다. 서버는 없습니다.
- 미국 지표(SOX·나스닥·EWY)를 그날 받지 못해 저장된 값으로 채웠거나, 휴장일 표에 없는 '미국 휴장'이면 **미리 보기**로 보여 주고 10분 뒤 다시 받습니다.
- 알림: 평일 오전 8:40(바꿀 수 있음) "오늘 코스피 예측이 준비됐어요". 숫자는 넣지 않습니다.

## 빌드 (GitHub Actions)

저장소 루트 = 이 폴더입니다. `main`에 푸시하거나 Actions 탭에서 **Build APK → Run workflow**를 누르면:

1. `npm ci` → `npm test`(분포 곡선·대상일·B2 규칙·시세 병합·model.js 해시) → `npx cap sync android`
2. `android/gradlew assembleRelease` (러너의 Android SDK, Java 21)
3. APK를 Actions 아티팩트로 올리고, **Releases**에 `v1.0.0-<실행번호>` 태그로 `market-compass.apk`를 붙입니다.

`versionCode`는 Actions 실행 번호라서 새 빌드는 항상 "업데이트"로 설치됩니다. 앱의 더보기 › 새 버전 확인은
`https://api.github.com/repos/hj5952009/mom-market-app/releases/latest`의 태그 번호와 앱에 찍힌 빌드 번호(`www/build.json`, CI가 기록)를 비교합니다.

로컬에서 웹 화면만 보려면: 아무 정적 서버로 `www/`를 열면 됩니다(네이티브가 아니면 자동으로 **체험용(데모) 모드**, 묶어 둔 실제 모델 결과 사용).

```
npm install
npm test                      # 단위 테스트 (node)
npm run screenshots           # 데모 화면 360×800, 글씨 1.0/1.3, 라이트/다크 → screenshots/ (Chromium 필요)
node tools/make-demo.js       # www/demo/*.json 다시 만들기 (../ref 필요)
python3 tools/make-icons.py   # 런처·알림·스플래시 아이콘 다시 만들기 (Pillow)
```

## 갤럭시 폰에 설치하기

1. 폰에서 GitHub 저장소의 **Releases**(최신 것)를 열고 `market-compass.apk`를 누릅니다(크롬이나 삼성 인터넷).
2. "이 유형의 파일은 기기를 손상시킬 수 있습니다" 같은 안내가 나오면 **다운로드**를 누릅니다.
3. 다 받으면 **열기**(또는 내 파일 › 다운로드에서 `market-compass.apk`)를 누릅니다.
4. "출처를 알 수 없는 앱" 안내가 나오면 **설정 › 이 출처 허용**을 켭니다(받은 앱이 크롬이면 크롬, 내 파일이면 내 파일에 대해). 뒤로 가서 **설치**.
5. Play 프로텍트가 "확인되지 않은 앱"이라고 하면 **세부정보 › 무시하고 설치**를 누릅니다(가족용이라 스토어 등록을 하지 않았기 때문).
6. 처음 열면 안내 한 화면이 나오고 **확인**을 누르면 시작됩니다. 알림 권한 창에서 **허용**을 누르면 아침 알림이 옵니다.

업데이트도 같은 방법으로 새 APK를 설치하면 저장된 시세는 그대로 남습니다(설정은 v2에서 새로 시작).

## 서명 keystore 안내 (꼭 읽기)

- 저장소는 **공개(Public)** 로 둡니다. 어머님 폰에서 로그인 없이 Releases를 내려받고, 앱의 '새 버전 확인'(인증 없는 GitHub API)이 동작하게 하려는 결정입니다.
- 모든 빌드가 같은 서명이어야 기존 앱 위에 업데이트 설치가 되므로, `android/app/family-release.keystore`(별칭 `family`)와 비밀번호(`android/app/build.gradle`에 평문)를 **저장소에 그대로 넣었습니다.**
- 그래서 **누구나 이 keystore로 같은 서명의 가짜 "업데이트" APK를 만들 수 있습니다.** 폰은 그런 APK도 정상 업데이트로 받아들입니다.
  **이 저장소의 Releases(https://github.com/hj5952009/mom-market-app/releases)에서 받은 `market-compass.apk` 말고는 어떤 APK도 설치하지 마세요.**
  카톡·문자·다른 사이트로 온 "시장 나침반 업데이트" 파일은 열지 않습니다.
- 이 keystore를 다른 앱이나 스토어 배포에 쓰지 마세요. keystore를 바꾸면 폰에서 기존 앱을 지우고 다시 설치해야 합니다(저장된 시세·설정이 지워짐).

## 자료와 안전 안내

- 시세: Yahoo Finance 비공식 차트 API. 개인적·비상업적 참고용이며, 늦거나 빠지거나 바뀔 수 있습니다.
- 숫자는 모두 모델 결과(`KModel.run`)에서 옵니다. 분포 곡선만 그 분위수로 앱에서 그립니다.
- 배포는 **가족 한정**입니다. 단톡방·카페·스토어에 올리거나 유료로 하면 유사투자자문업 등 법적 검토가 필요합니다.

## 폴더

```
www/                화면(빌드 도구 없는 HTML/CSS/JS)
  js/model.js       검증된 예측 모델(app-src/model.js와 같은 파일, sha256 테스트로 확인) — 수정 금지
  js/util.js        숫자·날짜 표기, KRX·NYSE 휴장일, 예측 대상일과 상태(확정/미리 보기/지난 예측)
  js/compute.js     모델 실행 + B2 규칙, 분위수 → 분포 곡선, 롤링 적중률 (worker.js에서도 실행)
  js/series.js      1달치 시세를 저장된 10년치에 이어 붙이기
  js/data.js        저장소·Capacitor 플러그인·시세 받기·데모 자료
  js/charts.js      SVG 차트 11종 + 툴팁·키보드
  js/app.js         탭 4개 화면·설정·알림·첫 실행 안내
  demo/             데모 자료 (실제 모델 결과 + 예시 시세)
android/            Capacitor 안드로이드 프로젝트 (gradle wrapper, keystore 포함)
test/               단위 테스트, 스크린샷 스크립트
screenshots/        검수용 화면 (데모 모드, 360×800, 글씨 1.0/1.3, 라이트/다크)
```

데모 주소 옵션(브라우저): `?tab=predict|record|info`, `&scale=1.3`, `&scenario=morning|usmissing`, `&now=ISO시각`, `&period=1m|3m|all`, `&notice=1`.
