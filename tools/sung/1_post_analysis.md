# 블로그 글 분석 지시 (성상현 '매크로 비욘드' 블로그)

목적: 가족용 코스피 예측 앱 '시장 나침반'에 들어갈 **성상현 페이지**용 데이터를 만든다.
독자: 주식·경제를 조금만 아는 50~60대 어머니 + 경제학과 4학년 아들. 쉬운 말이 우선.

## 입력
`chunks/cNN.jsonl` — 한 줄에 글 하나: {id, date, cat(카테고리), title, likes, text}
배정받은 파일의 **모든 줄을 빠짐없이** 읽는다 (파일이 크면 Read를 offset/limit으로 나눠 끝까지).

## 출력
`out/cNN.json` (같은 번호) — 아래 모양의 JSON 하나. Write 도구로 저장하고, 저장 뒤 `python3 -c "import json;json.load(open('out/cNN.json'))"`로 문법 확인.

```json
{
  "chunk": "cNN",
  "posts": [
    {
      "id": "224441942964",
      "oneLine": "40자 이내 핵심 한 줄",
      "summary": "2~3문장, 200자 이내. 글쓴이가 무엇을 왜 주장하는지.",
      "kind": "시장진단|개념설명|투자원칙|기관리서치|독서|영상추천|공지·행사|기타",
      "themes": ["아래 주제 목록에서 1~3개"],
      "view": "시장·경제에 대한 그의 판단이 있으면 한 문장(없으면 \"\")",
      "tone": "긍정|중립|경계",
      "indicators": ["아래 지표 코드 중 글에서 실제로 중요하게 다룬 것"],
      "level": 1,
      "value": 3,
      "principle": "투자 태도·원칙 교훈이 있으면 한 문장(없으면 \"\")",
      "terms": [{"term": "용어", "plain": "어머니도 알 쉬운 설명 한두 문장"}]
    }
  ],
  "highlights": [{"id": "...", "why": "앱에 꼭 넣을 만한 이유 한 줄"}],
  "chunkNote": "이 기간(날짜 범위) 그의 생각 흐름을 4~6문장으로: 무엇을 걱정/기대했고 주된 논리는 무엇이었는지"
}
```

### 주제(themes) — 이 목록에서만 고른다
연준·통화정책 / 금리·채권 / 물가 / 재정·부채 / 달러·환율 / AI·반도체 / 빅테크·투자사이클 / 유가·원자재 / 고용·경기 / 중국·신흥국 / 한국 경제·증시 / 자산배분·전략 / 투자 마인드 / 금·대체자산 / 신용·유동성 / 지정학·정책

### 지표 코드(indicators)
fed(연준), us10y(미국 장기금리), us2y(단기금리), cpi(물가), jobs(고용), oil(유가), usd(달러), krw(원/달러), gold(금), ai(AI 투자), semis(반도체), bigtech(빅테크), credit(신용·하이일드), liquidity(유동성·M2), fiscal(재정적자·국채발행), china(중국), em(신흥국), kospi(코스피·한국증시), sp500(미국증시), vix(변동성), housing(부동산), btc(비트코인)

### 점수
- level: 1 쉬움(일반인도 이해) · 2 보통 · 3 어려움(전문 용어 많음)
- value: 앱에 실을 가치 1~5. 5 = 시장을 보는 틀을 주거나 어머니께 꼭 보여 드릴 글. 공지·홍보·감상 위주면 1~2.
- 사진·영상 추천·이웃 이야기·행사 공지는 짧게 처리(summary 1문장, value 1~2).

## 꼭 지킬 것
1. **원문 문장을 그대로 옮기지 않는다.** 모든 요약·한 줄·관점은 네 말로 다시 쓴다(인용부호 속 원문 복사 금지, 5어절 넘게 똑같이 쓰지 않기).
2. 그의 주장은 "~라고 본다 / ~를 강조한다"처럼 **그의 관점으로** 쓴다. 사실처럼 단정하지 않는다.
3. **매수·매도 지시형 표현 금지**: "사라/팔아라/매수하세요/추천" 같은 말을 쓰지 않는다. 종목 추천이 있는 글이면 "~기업을 긍정적으로 본다" 수준으로만.
4. 숫자(금리 5%, 유가 등)는 글에 나온 그대로 정확히. 모르면 쓰지 않는다.
5. 쉬운 한국어, 존댓말 아닌 평서체("~다").
6. 모든 글(id)을 하나도 빠뜨리지 않는다. 출력 posts 수 = 입력 줄 수.

마지막 답(최종 메시지)은 "cNN: 글 N개 처리, 저장 완료" 한 줄만.
