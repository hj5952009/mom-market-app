# 주제별 종합 지시

`synth/theme_NN.txt`는 성상현(블로그 '매크로 비욘드') 글 중 한 주제에 해당하는 글 목록이다(날짜순, 각 줄: 날짜 | id | 앱가치 | 톤 | 제목 | 한 줄 | 관점). 이미 우리가 쓴 요약이다.
독자: 50~60대 어머니(주식 초보)와 경제학과 아들. 가족용 코스피 예측 앱의 '성상현' 페이지에 들어간다.

배정받은 각 주제 파일을 **끝까지** 읽고, 주제마다 아래 JSON을 만든다. 결과는 `synth/theme_NN.json`(같은 번호)으로 저장하고 json 문법을 확인한다.

```json
{
  "theme": "주제 이름",
  "headline": "그가 이 주제를 보는 핵심을 25자 안팎 한 줄로",
  "plain": "어머니도 이해할 쉬운 설명 2~3문장: 이 주제가 무엇이고 왜 시장에 중요한지(일반 설명, 그의 관점 아님)",
  "core": "그의 일관된 관점 3~4문장 (그는 ~라고 본다)",
  "shifts": [
    {"period": "2024년 상반기", "text": "그 시기 그의 생각 한두 문장", "ids": ["대표 글 id 1~2개"]}
  ],
  "now": "가장 최근(2026년 9~10월) 그의 입장 2문장",
  "watch": ["그가 이 주제에서 확인하라고 하는 지표·신호 2~4개, 각 20자 안팎"],
  "best": ["이 주제를 이해하기 가장 좋은 글 id 4~6개 (앱가치 높은 것, 시기 고르게)"]
}
```
shifts는 3~6개, 시간순. 

규칙: 자기 말로 쓴다(목록 문장 그대로 붙여넣기 금지), 그의 관점은 "~라고 본다"로, 매수·매도·추천 같은 지시형 표현 금지, 숫자는 목록에 있는 것만, 평서체("~다").
마지막 답은 "주제 NN, NN 저장 완료" 한 줄.
