# 증시 관점 점수 매기기

`stance/sN.jsonl` 각 줄은 성상현 블로그 글 하나의 요약(우리가 이미 쓴 것): id, date, title, kind, oneLine, summary, view.
각 글이 **앞으로 몇 주(1~4주) 주식시장(한국·미국 증시)**에 대해 어떤 판단을 담고 있는지 점수를 매긴다.

- stance: -2(뚜렷한 하락·조정 경고, 위험 줄이기 강조) / -1(경계 쪽) / 0(중립·양면·판단 없음) / +1(긍정 쪽) / +2(뚜렷한 상승 기대, 조정은 기회)
- rel: 0(시장 전망과 무관: 투자 마음가짐 일반론, 독서, 영상, 공지, 개념 설명만) / 1(간접적: 거시 설명 위주) / 2(직접: 증시 방향·조정·대응을 말함)
- kr: 1이면 한국 증시를 직접 다룸, 아니면 0

규칙:
- **글의 내용만으로** 판단한다. 그 뒤에 시장이 실제로 어떻게 됐는지(알고 있다고 생각되더라도) 절대 반영하지 않는다.
- 장기 낙관 + 단기 조정 경고가 같이 있으면 1~4주 기준으로 단기 쪽에 무게를 둔다.
- rel=0이면 stance는 0.
- 모든 줄을 빠짐없이 처리한다.

출력: `stance/sN.out.json` → {"id": [stance, rel, kr], ...} 형태의 JSON 하나. 저장 후 python으로 문법과 개수(입력 줄 수와 같음) 확인.
최종 답은 "sN: N개 저장" 한 줄.
