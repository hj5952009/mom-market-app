# 성상현 페이지 자료 만들기 (www/data/sung.json)

원본: 황나 블로그 아카이버가 내보낸 `hwangna-blog-archive/v1` JSON(블로그 ssh_fedinsight). **원문은 저장소에 넣지 않는다.**

1. 사진 모음을 뺀 글을 약 11만 자씩 묶음으로 나눈다.
2. 묶음마다 `1_post_analysis.md` 지시로 글별 요약·주제·관점·원칙·용어를 만든다(원문 문장 복사 금지, 매수·매도 지시 금지).
3. 주제 16개별로 `2_theme_synthesis.md` 지시로 핵심 관점·변화·신호를 종합하고, 원칙 약 20개·용어 약 50개로 묶는다.
4. `synthesis.json`(지금의 관점·확인 신호·시장 읽는 틀·시기별 흐름·전망 글)은 사람이 검토해 쓴다.
5. `build_data.py`로 합쳐 `www/data/sung.json`을 만든다. `npm test`가 연결 글·금지 표현·본문 미포함을 확인한다.

새 글이 쌓이면: 새로 내보낸 JSON에서 이미 분석한 글(id)을 빼고 2번만 새 글에 돌린 뒤 3~5번을 다시 한다.
