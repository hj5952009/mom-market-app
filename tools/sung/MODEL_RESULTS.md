# 성상현 관점 모델 검증 (2026-10-15, 실제 Yahoo 시세 + 모델 워크포워드 기록 800일)

관점 지수 S: 글별 1~4주 증시 관점 점수(−2~+2, 관련도 가중)를 예측일 08:30 전 글만, 반감기 7일로 평균.
검증: 날마다 그 전 날들로만 로지스틱 회귀를 다시 맞춤(처음 120일 학습), 2024-09-30 ~ 2026-10-14, 494거래일.

| 예측 | 방향 적중 | 브라이어 | 로그손실 |
|---|---:|---:|---:|
| 모델 그대로 | 63.8% | – | – |
| 모델 다시 보정(기준) | 63.4% | 0.2146 | 0.6168 |
| + 관점 지수 S | 64.2% | 0.2154 | 0.6186 |
| + 글 전체 톤 T | 65.2% | 0.2148 | 0.6173 |

- 방향이 갈린 6일 중 관점 반영 5일, 기준 1일 맞힘 (p≈0.10, 의미 없음). 브라이어·로그손실은 오히려 조금 나빠짐.
- S와 이후 코스피 수익률 상관: 다음 날 +0.02(p 0.61), 5일 +0.09(p 0.33), 20일 +0.06(p 0.77). 모델 잔차와 +0.02(p 0.63).
- S와 그날 출렁임 크기(|오차|/예측 표준편차) 상관 −0.02(p 0.63).
- S < 0인 날은 20%뿐(범위 −0.69 ~ +0.82): 거의 늘 장기 낙관.
- 결론: 통계적으로 의미 있는 개선 없음 → 기본 예측(model.js)에는 넣지 않고 성상현 탭 '모델'에서 실험값으로만 보여 줌.
